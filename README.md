# 🗂️ estruturaDeDados

Repositório da disciplina de **Estrutura de Dados** do curso de Desenvolvimento de
Software Multiplataforma (Fatec Mauá). Foco: organização eficiente de dados,
análise de complexidade e resolução de problemas.

## 📚 Conteúdo

| Atividade | Linguagens | Descrição |
|---|---|---|
| `atividade1_HelloWorld` | C#, C, C++, Java, Python | Primeiro contato com múltiplas linguagens — comparação de sintaxe e compilação |

## 🗺️ Roadmap de estudos

- [ ] Vetores e matrizes
- [ ] Listas ligadas (encadeada simples e dupla)
- [ ] Pilhas e filas
- [ ] Algoritmos de busca (sequencial, binária)
- [ ] Algoritmos de ordenação (bubble, insertion, quick, merge)
- [ ] Árvores (BST, percursos)
- [ ] Notação Big-O e análise de complexidade

## 🛠️ Como executar

Cada pasta contém a mesma atividade em linguagens diferentes:

```bash
# C# (.NET)
dotnet run --file atividade1_HelloWorld/HelloWorld.cs

# C (compilação com GCC)
gcc atividade1_HelloWorld/HelloWorldC.c -o hello && ./hello

# C++ (compilação com G++)
g++ atividade1_HelloWorld/HelloWorldCpp.cpp -o hello && ./hello

# Java
javac atividade1_HelloWorld/HelloWorldJav.java && java HelloWorldJav

# Python
python3 atividade1_HelloWorld/HelloWorldpy.py
```
